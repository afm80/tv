# بوت قنوات Alfaham TV

يجلب القنوات من iptv-org ويكتبها في Firebase بنفس هيكل لوحة التحكم، ويعمل بالتنسيق معها دون تعارض.

## ماذا يفعل
- **القسم العربي:** يطابق أقسام الدول الموجودة، وينشئ الدولة الناقصة (باسمها وعلمها).
- **القسم العالمي:** يغطي **كل دول المصدر** (`"countries": ["*"]`) ما عدا العربية، وينشئ قسماً لكل دولة لها قناة شغّالة.
- يفحص كل رابط (يعمل + CORS + ملف HLS صالح) ولا يضيف إلا الشغّال.

## سلوك التحديث (لا يحذف شغّالاً أبداً)
في كل تشغيل يبدأ البوت بفحص القنوات التي جلبها سابقاً **رابطاً برابط**:
- الرابط الشغّال **يبقى** كما هو.
- الرابط الميت **يُستبدل** برابط شغّال من المصدر لنفس القناة (إن وُجد).
- القناة **لا تُحذف** إلا إذا ماتت **كل** روابطها ولم يوجد بديل، وفي `deleteAfterFailures` تشغيلات متتالية (الافتراضي 2، فالعطل العابر لا يحذف شيئاً). أول فشل يضع عدّاد `fails` فقط، وأي نجاح يمسحه.
- القناة التي سحبها المصدر (مغلقة/محظورة/مستثناة) أو أضفتَ مثلها يدوياً تُحذف.
- **السقف** (`maxChannelsPerCountry`, `maxChannelsWorld`) يحدد عدد القنوات الجديدة فقط: تدخل قناة جديدة فقط إذا وُجدت خانة فارغة، ولا تُزيح قناة شغّالة. `0` = بلا سقف.
- إذا فشل **50% أو أكثر** من القنوات الموجودة دفعة واحدة (انقطاع شبكة/مصدر) لا يُسجَّل أي عطل ولا يُحذف شيء.
- لا يكتب شيئاً إن لم يتغير شيء، فلا تُعاد تحميل صفحات المشاهدين دون داعٍ.
- **حفظ تدريجي:** يكتب النتائج دولة بعد دولة (بعد قراءة طازجة قبل كل دفعة)، فإذا انقطع التشغيل أو انتهت مهلته يبقى كل ما أُنجز، ويكمل التشغيل التالي من حيث بقي.

## التنسيق مع لوحة التحكم وقاعدة البيانات
- يقرأ الحقول بنفس طريقة الموقع واللوحة: `categoryIds` ثم `categories` ثم `categoryId`/`catId`، والروابط في `links` (نص أو `{url,label}`) والحقول القديمة (`mainLink`, `url`, ...). ويكتب `categoryIds` و`categories` معاً.
- يكتب **حقولاً محددة** وليس السجل كله، فأي حقول أخرى أضفتها للقناة تبقى.
- بعد انتهاء الفحص (قد يطول) **يعيد قراءة القاعدة** ثم يدمج: لا يطغى على قناة عدّلتها أو حذفتها أو غيّرتَ أقسامها أثناء تشغيله (القناة المعدّلة تصبح محمية `manual`).
- قناة بوت تعدّلها من اللوحة تصبح محمية (`manual: true`) ولا يلمسها. وإذا حذفتها تُسجَّل في `botIgnore` ولا تعود.
- قسم أنشأه البوت وحذفته من اللوحة يُسجَّل في `botIgnoreCats` ولا يعود. (لإيقاف دولة نهائياً ضعها في `excludeCountries`.)
- أقسامك الموجودة لا يعيد البوت كتابتها، ويملأ الصورة الفارغة بالعلم فقط. والأقسام الإضافية التي تضيفها لقناة بوت تبقى.
- قفل في `botMeta/lock` + `concurrency` في GitHub يمنعان تشغيلين متزامنين. وآخر نتيجة في `botMeta/lastRun`.

## الإعدادات (config.json)
- `sections`: أسماء القسمين والدول (رموز ISO، وبريطانيا `UK`). `"*"` = كل دول المصدر.
- `maxChannelsPerCountry` / `maxChannelsWorld`: سقف القنوات لكل دولة (عربية / عالمية). الإعداد الحالي: العربية `0` (بلا سقف) والعالمية `0` (بلا سقف). انتبه: كل القنوات تُحمَّل في صفحة الموقع، فارفع الرقم تدريجياً وراقب السرعة.
- `deleteAfterFailures`: عدد التشغيلات المتتالية الفاشلة قبل حذف قناة ميتة (1 = فوراً).
- `checkRetries`: إعادة فحص روابط القنوات الموجودة قبل الحكم عليها بأنها ميتة.
- `checkConcurrency`, `checkTimeoutMs`: سرعة فحص الروابط.
- `excludeCountries`: دول لا يتعامل معها البوت إطلاقاً.
- `createEmptyCountries`: `true` ينشئ قسماً لكل دولة حتى لو لم توجد لها قناة شغّالة (الافتراضي `false`).
- `blockNamePatterns`: أسماء قنوات تُستثنى.
- `siteOrigin`: ضع رابط موقعك الحقيقي ليكون فحص CORS دقيقاً.

## التشغيل
Actions ← Sync channels ← Run workflow. خانة `dry` = تجربة بدون كتابة (تطبع التقرير وقائمة الدول التي لا قناة شغّالة لها مع السبب).
المفتاح يوضع في Secrets باسم `FIREBASE_SERVICE_ACCOUNT` ولا يُرفع للمستودع.
اختبار المنطق محلياً: `cd bot && npm test` (يعمل أيضاً قبل كل مزامنة في GitHub Actions).

## الأقسام حسب الفئة (categorySections)
بالإضافة لأقسام الدول، يربط البوت كل قناة بقسم فئتها (أخبار، وثائقية، دينية، طبخ، رياضة، أطفال، ترفيه...) حسب فئات iptv-org.
- **بسجل واحد:** القناة نفسها تظهر في قسم دولتها وقسم فئتها معاً (`categoryIds` فيها أكثر من قسم) دون تكرار القناة.
- **المطابقة بالاسم:** يطابق الأقسام الرئيسية الموجودة بأحد الأسماء في `names` (دون اعتبار الهمزات)، وينشئ الناقص بالاسم الأول عند وجود قناة له.
- **`scope`:** `all` كل الدول، `arab` دول القسم العربي فقط، `world` ما عداها. الإعداد الحالي: كل الأقسام `all` (تُجلب الفئة بكل قنواتها عربية وأجنبية) عدا الرياضة التي تنفصل بدولة القناة (عربية/عالمية).
- **دمج الفئات:** الوثائقي = documentary+culture+education+science، المنوعة = lifestyle+travel+outdoor+relax+business+weather+shop+family+public+auto+general، الأطفال = kids+animation، الأفلام = movies+classic.
- **للتعطيل أو الإضافة:** `"enabled": false` يوقف قسماً، وأي إدخال جديد يحتاج `key` فريداً و`names` و`categories`.
- قسم فئة حذفته من اللوحة يُسجَّل في `botIgnoreCats` ولا يعود. وأقسامك الإضافية على قنوات البوت تبقى كما هي.

## تقرير فئة (قراءة فقط)
لمعرفة حجم أي فئة في المصدر دون أي كتابة أو عرض روابط: Actions ← **Category report** ← Run workflow، واكتب اسم الفئة (مثل `news`) وفعّل `names` لعرض الأسماء. أو محلياً: `node bot/report.mjs news --names`.
يطبع العدد الكلي وعدد القنوات التي لها رابط https والتوزيع حسب الدولة. لا يتصل بقاعدة بياناتك إطلاقاً.
